## 模块

「通用内容管理系统」提供通用的动态模型内容管理系统。

```mind
功能特性
    模型管理
        模型动态字段
        多模型支持
        自定义字段类型
    栏目管理
        多级分类
        栏目排序
        栏目模板独立设置
    内容管理
        内容发布与编辑
        内容审核
        内容备份恢复
    展示功能
        多模板支持
        匿名点赞
        SEO优化
    扩展能力
        标签管理（TagManager）
        网站地图（SiteMapManager）
        中文分词（WordSpliter）
        多语言内容（I18nArticle）
```



## 模块入口

- `/cms` CMS首页
- `/tag/{tag}` 标签页
- `/a/{alias_url}` 内容页
- `/c/{id}` 栏目页
- `/search` 搜索
